Which side the bubble sits on is invisible

Every chat interface says who is talking with position and colour, and a screen reader has neither. Without help the whole conversation arrives as one block of text with no idea who said what. So every message carries its speaker as a word, said once in front of the content — "Mai, 09:12", "You, 09:15" — even on the second bubble of a run, where the name is hidden from sight.

Runs, worked out rather than declared

Mai's first two messages share one avatar and one timestamp. The component reads its own neighbours to decide that; the markup declares nothing. Her last message is 15:40 — six hours later, so it starts a new run rather than inheriting a timestamp from this morning.

The thread belongs to the page

role="log" sits once on the <ol>, not on each message. A page can hold several conversations and only the page knows which of them should announce itself; putting a live region on every bubble means each arrival interrupts the one before it.
