A receipt is not a colour

Walk the four buttons. Two grey ticks against two blue ticks — the usual design — differ by colour alone, which is exactly what a state must never do. Each state here has its own glyph and its own word: a clock, one tick, two ticks, two ticks in a ring.

A failure needs an answer, not an acknowledgement

The failed message keeps its receipt while every other bubble in its run hides one, because it is the only state that asks something of the reader. Press Try again: it fires chat-retry, and this page answers it.

A system notice is not somebody talking

It sits in the middle with no bubble, no avatar and no side — and it never joins a run, because a run is one person speaking and this is not a person.

Nothing a message contains can break the thread

The last message is one unbroken string longer than the bubble. Without overflow-wrap: anywhere it would push the bubble past the thread and take the layout with it — a URL somebody pasted is the everyday version of this.
