  1. Hi — quick one about tomorrow. The room is booked from ten, but the projector cable is missing, so bring yours if you have it. Otherwise we can share a screen. See you then.

  2. Got it, I'll bring the cable.

  3. Also — I moved the standup to nine thirty so it does not clash. Shout if that is a problem for anyone.

A voice note with no transcript is a message some people cannot read

This is the whole design of this variant. Audio is not an accessible format, and a waveform is not a substitute for it — the transcript is part of the contract here rather than an enhancement somebody remembers. Press Show transcript on either note.

The waveform is decoration, and says so

Those bars are a fixed pattern, not an analysis of the audio. They carry aria-hidden because nothing in them is information. A waveform drawn to look like a real one, for audio it never measured, would be a picture that lies.

One at a time

Start the second note while the first is playing. The first stops — two voice notes talking over each other is nobody's idea of a conversation. The button names the length and its own state, so the control reads as "Voice message, 0:06" and then "Pause".

About this audio

The file is synthesized rather than recorded — a recording is somebody's voice, and this one ships in a public repository. It is a real, playable 8 kHz WAV that lives beside the component; nothing here reaches the network.
