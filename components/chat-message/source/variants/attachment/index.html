A file is named before it is opened

The name and the size are both visible and both in the link's accessible name — "Download Quarterly review.pdf". A paperclip with no filename asks somebody to download a thing to find out what it is, which is a worse offer on a metered connection and an impossible one for a screen reader.

Sizes are written the way a person says them: 2.3 MB, 47 KB. Bytes are for machines.

Links inside your own bubble

The blue a link normally uses is invisible on a blue bubble. Inside your own messages links take a near-white ink instead, measured at 5.77 light and 4.56 dark against the accent — and keep their underline, because on a saturated background colour alone is not a distinction anyone should have to make.

The download attribute is the author's

This component does not fetch anything or manage a download. It is an ordinary <a download> in the markup; the component gives it a name, a size and a shape. Everything else is what the browser already does well.
