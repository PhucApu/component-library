Three ways to move it

Drag it with the pointer, press the controls in the corner, or tab to the map and use ← → ↑ ↓ to pan, + and - to zoom, 0 to start again. The keyboard is not an afterthought here: a map that can only be dragged is a map half the room cannot use.

Panning by key moves less the closer you are, so one press covers roughly the same amount of what you can see whatever the zoom.

Whose controls are these?

The provider brings its own zoom control, and the component's three sit in the corner beside it. Both work, because both end up calling the same zoomBy on the same adapter. Nothing here reaches past the seven members into the map itself.

Panning by key is the component's, and it asks the adapter to move rather than moving anything itself — which is the reason the keys still work when the surface underneath them is swapped for a different one.
