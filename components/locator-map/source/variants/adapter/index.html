The map is not part of the component

The component owns the search, the ranking, the directory, the announcements and the decision to go somewhere. The surface that actually moves is an adapter it is handed, and the drawing that ships is only one implementation of it.

The map below starts as a real provider's, like every other variant. The buttons swap it for two others without the search losing its place: a grid written on this page in about thirty lines, and the drawing that ships with the component. All three answer the same seven members.

Handing over after the page has loaded

Setting adapter again tears the old surface down and mounts the new one in the same frame. That is what lets a page start with the drawing and hand over to a provider's map once its script has arrived, without the search losing its place.

Which provider, and what it costs

The same seven members drive Google Maps, Leaflet or anything else: mount, update, flyTo, reset, zoomBy, view, destroy. Which one this catalog loads is set in one place, source/real-map.js: Leaflet by default because it needs no key, Google by pasting one in.

The price is real. This is the only component in the collection that reaches the network, so its packaged download needs a connection, and both the tests and the preview build depend on somebody else's servers. Press Use the drawing to see what it looks like with that price not paid.
