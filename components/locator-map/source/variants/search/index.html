What comes first, and why

Type ha. A name that starts with what you typed comes before one that merely contains it, and both come before a match found only in the street: somebody typing two letters means the city, not an address that happens to hold them.

The keyboard, and the empty answer

↓ and ↑ move through the results, Enter chooses, Escape closes the list. Type something that matches nothing — zzz — and the list says so rather than vanishing, which would leave you wondering whether it was still working.

Marks that are not in this page

The search folds both sides before comparing, so a consumer whose own data carries Vietnamese marks can be searched without typing any: every tone and vowel mark comes off, and d with stroke is mapped by hand because it is one letter rather than a letter with something added, and no amount of normalising takes it apart. The match is then marked on the folded text but cut from the original, so the result is still shown written the way it was written.

None of that can be shown here: this repository keeps its own text unaccented and a check enforces it. The folding is covered by unit tests instead, which spell the marked letters as escaped code points.
