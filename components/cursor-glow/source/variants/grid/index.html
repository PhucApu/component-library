Each one lights itself

Every region listens only to the pointer inside it, so moving across the row hands the light from one to the next and never lights two at once. Nothing co-ordinates them: there is no parent keeping score, which is why a region can be dropped anywhere on a page on its own.

Leaving one does not switch it off at the border — it goes out where the pointer left, which is what stops the row from flickering as you cross the gaps.
