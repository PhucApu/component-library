One number is not a chart

A single current value drawn as a one-bar bar chart spends an axis, a grid and a legend saying what the number already said. The tile is the honest form: the value leads, the change explains it, and the sparkline is context rather than a second reading to compare.

What the markup carries, and what the script adds

The label, the value and the change are ordinary paragraphs — turn scripting off and the headline is untouched. The only thing the script draws is the sparkline, and the twelve readings it drew from stay in the page for anything that reads rather than looks.

data-value carries the number while the text carries the wording, so $48,290 is never reformatted into something the author did not write. The line recedes and only the current reading takes the accent: context should not compete with the number it is context for.
