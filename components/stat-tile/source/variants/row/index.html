A row of tiles is layout, not a component

There is no <ui-stat-row> here on purpose. A row arranges tiles and adds no meaning of its own, and a wrapper element would invite a date filter inside each card — when the rule is one filter row above everything it scopes, so every number on the page always agrees with every other.

Why the lines agree across the row

The row is a grid with subgrid rows, so every label, every value and every change sits on the same line as its neighbours. Without it each tile packs its own contents and a longer label in one card pushes that card's number out of step with the rest — which reads as sloppiness before anyone can say why.

Four tiles, four judgements: revenue up is good, accounts down is bad, cost up is also bad, and headcount is neither. Same arrows, four different meanings.
