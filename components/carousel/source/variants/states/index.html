One picture is not a carousel

The arrows and the dots are removed rather than turned off. Controls that could never do anything are furniture, and they take tab stops with them.

Ends that are real ends

Without loop the arrow at each end turns off. It hands focus to the other arrow first — a disabled element cannot hold focus, and the control turning itself off is usually the one under the finger.

  • First — the previous arrow is off

  • Middle — both arrows work

  • Last — the next arrow is off

Ends that join up

With loop neither arrow ever turns off, and the last picture leads back to the first.
