Moving on its own, and stoppable

Content that starts moving by itself has to be stoppable, so the pause control is part of the component rather than an option. It also stops on its own whenever the pointer is over it, whenever anything inside it has focus, and whenever the tab is in the background.

Under a reduced-motion setting it never starts at all. Slowing it down would be answering the wrong request.

  • Hover to hold it still

  • Tab into it and it waits

  • Switch tabs and it stops

  • Press pause and it stays stopped

Without looping it stops at the end

A slideshow that jumps back to the beginning without being asked is a surprise, so it plays to the last picture and stops there.
