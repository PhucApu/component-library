A track that scrolls, with everything else added on top

The track is an ordinary scroll container with snap points. Swiping, momentum and keyboard scrolling all come from the browser; turn scripting off and it is still a usable strip of pictures. The arrows, the dots and the pointer dragging are what the component adds.

Tab to the strip and use ← and →, or drag it with the pointer. A drag that travels far enough, or moves fast enough, changes picture; anything less falls back to where it was.
