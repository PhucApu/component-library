The triangle a cohort grid always is

Each row is a month's intake and each column is how many months later. Newer cohorts have not lived long enough to fill the row, so those cells are empty rather than zero — and the staircase of missing squares is the shape that tells you which rows are still in progress.

A ceiling you set, so two grids agree

max="100" pins the top of the scale. Without it each grid scales to its own busiest cell, and two retention charts side by side use the same colours for different numbers — which is a comparison that quietly lies.

Long row names

Row labels take whatever width they need and the cells start after them. Nothing is truncated: a cohort called February that reads as Febr… is a row somebody has to hover to identify.
