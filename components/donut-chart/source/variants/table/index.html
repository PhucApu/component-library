The same contract as the other charts

An ordinary <table>: first column the names, second column the values. Nothing configured in JavaScript, nothing fetched. Press Show the table — it is not a copy generated beside the ring, it is what the ring was drawn from.

Here the table earns its place twice over. On a bar chart it is a second way to read the values; on a ring it is the only accurate one, because a wedge is an angle and nobody reads angle to three figures.

Written for a person, plotted as a number

The cells say 412.5 GB and the ring divides 412.5. The hole and the legend both show the author's own wording rather than a reformatted version of the same number. Where the text cannot be parsed with confidence — a decimal comma above all — data-value settles it.

With no script

A complete, readable table of every bucket and every figure. For a page whose subject is a breakdown, that is most of what anyone came for — and it is the same markup, not a fallback written twice.
