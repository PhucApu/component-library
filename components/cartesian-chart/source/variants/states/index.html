There is one colour, and the caption already says what is plotted. A box holding a single swatch restates the title and costs a line. Two series or more and the legend is always there — never optional, because matching colours by eye against the plot is not a thing anyone should be asked to do.

The ninth colour is never invented

There are eight categorical slots and the order they sit in is what keeps every neighbouring pair apart for a reader with colour blindness. A generated ninth is indistinguishable from one already on screen under simulation, so the ninth series onward is simply not drawn and the note says where to find it.

fold-others sums the tail into a single Other series instead. That changes what the author wrote, so it is something to ask for rather than something that quietly happens.
