Enough pictures that the strip has to move

The arrows at each end of the strip scroll the strip; they do not change the picture. Pressing a thumbnail is what changes it. When you move with the main arrows and the matching thumbnail has scrolled out of sight, the strip slides just far enough to bring it back — a mark showing where you are is no use if nobody can see it.

This gallery also loops, so the arrows never run out. Compare with the others, where the ends are real ends and the arrow turns off.
