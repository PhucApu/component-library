Not a dialog, so none of the dialog rules apply

This panel is a `nav`, not a `dialog`. It does not trap focus, it does not take Escape, and it does not cover anything — it pushes the content beside it. The mode comes from the element the author wrote, so the two can never disagree.

Workspace overview

  • The content keeps its own scroll and its own focus order.
  • Nothing behind it is inert, because nothing is in front of it.
  • Closing the panel simply gives the width back.
