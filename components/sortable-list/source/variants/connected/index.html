Done

    Left and right, and only where there is somewhere to go

    ← and → are bound only on a list that has a group. On a list on its own they stay unclaimed — binding them would imply a direction that does not exist, and send a keyboard user looking for it. ↑ and ↓ then move within whichever list the row is currently over.

    The empty list is a target before you need it

    Done has no rows, so it has no gap between rows to aim at. Its empty message doubles as the drop zone — and it is there from the start, not conjured when a drag begins. A zone that appears under the pointer shoves the rest of the board aside at the exact moment somebody is aiming at it.

    The announcement names the list

    A cross-list move that says only "position 2 of 4" has left out the one thing that changed. Every step says where: "Deploy to staging, Done, position 1 of 1." Each list is named by name, falling back to whatever labelled it for everyone else.
