The markup is the data and the fallback

No configuration object, no fetch. An ordinary table goes in and it does three jobs at once: it is the data, it is what remains when the script does not run, and it is what a screen reader reads. Only the first value column is plotted; a second one is somebody's extra metric and is left alone rather than drawn as a stage.

Row order is stage order

Nothing is sorted. A funnel sorted by size is no longer a funnel — it is a bar chart that has thrown away the sequence, which was the only reason to draw a funnel in the first place.

Where the numbers come from

data-value settles anything ambiguous, so a cell can read 1,240 or 1.2k for a person while the chart gets the figure. Without it the text is parsed, which handles thousands separators and currency symbols but not an abbreviation.

The table is the accessible reading

The bars carry aria-hidden in their entirety. Every word beside them is either already in the table or already in the summary line above, so exposing both would read the funnel twice. What the table cannot hold — the conversion rates, which are computed rather than given — is in that summary and in the announcement when you walk the stages with the arrow keys.
