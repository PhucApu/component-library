The cord decides nothing

All the component does is hold a state, reflect it as an attribute, and say so when it changes. It does not know what a theme is. The room below is lit by a page listening for light-pull-change, and the panel beside it swaps its own color-scheme from the same event.

That is the reason it is worth building this way: the same cord can work a lamp, a theme, a preference, or nothing at all.

One cord, two listeners.
