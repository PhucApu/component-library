On to begin with

on is an ordinary attribute and it is reflected, so a page can open with the light already on and can always read the state back. The handle carries it as aria-checked, which is what a screen reader announces.

Already on.

Without a pointer

Tab to the handle and press Space or Enter. The cord is tugged and the switch works — the same control, reached a different way. The handle is a real role="switch", not a shape drawn in the cord, which is the only reason that sentence can be true.

Reduced motion

Under prefers-reduced-motion the cord does not swing: the switch works, and the cord is where it hangs. The swing is the whole of what is left out, and none of what it does is lost with it.
