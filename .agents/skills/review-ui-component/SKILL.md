# Review UI Component

Always operate read-only.

## Review scope

- Manifest schema, group, variant descriptions, thumbnail path, and safe entries.
- Independent source and assets without catalog or framework dependencies.
- Variant behavior, value contract, states, responsive behavior, and reduced motion.
- Semantic HTML, accessible names, keyboard operation, focus management, contrast, and errors.
- README, DESIGN, PROMPT, manifest, and source consistency.
- Registry, source inspection, preview, document downloads, and ZIP distribution contract.

Report findings by severity with file and line references when possible. Report the status of
each delivery gate. Do not edit, format, generate, preview, or package files in review-only mode.
